ChameleonTools 是一套专业的音频与音乐工具集合 —— 使用 FreePascal 和 Lazarus 构建的桌面应用，以及一个用于 Raspberry Pi 的无头（headless）录音操作系统。每个工具都能独立使用，但它们组合起来构成了音乐人、音频工程师和制作人的完整工作流程 —— 从作曲与声音设计到混音、母带处理和乐器设置。

每个工具都是免费、开源且跨平台的（Windows、macOS、Linux）。没有订阅，没有加密狗，没有供应商锁定。下载、使用、修改并贡献。

MIDI 生成

ChameleonDrummer

一个动态的 MIDI 鼓生成器，可将风格、类型、鼓手和拍号转换为逼真的、富有人类感觉的鼓轨。它导出的 MIDI 文件可导入任何 DAW、鼓软件或乐谱程序。

适用人群：需要逼真鼓轨但又没有鼓手或完整鼓组的词曲作者、制作人和作曲家。也适用于生成创意、勾勒编曲和制作伴奏轨。

与众不同之处：它不只是循环采样 —— 它建模鼓手风格（Bonham、Porcaro、Chambers、Roeder、Dee、Hoglan 等另外 10 位）、应用人性化处理（时序抖动、鬼音、摇摆）并遵守物理可演奏性限制。结果听起来像真正的鼓手，而不是机器。

  • 5 种类型、37 种风格、17 个鼓手档案
  • 多键位映射支持（GM、AD2、EZDrummer 3、Yamaha XG、自定义 JSON）
  • 复合拍与奇数拍（5/4、7/8、9/8、11/8、13/8，最高 32/16）
  • 三连音感觉、摇摆与人性化
  • REAPER 和 Ardour 会话导出
  • 用于批量生成的 CLI，用于交互式使用的 GUI

音频卷积与母带处理

TaraDSP

一个专业的基于 FFT 的卷积处理器，用于箱体模拟、卷积混响和母带级音频处理。它可以将脉冲响应以录音室品质应用到音频信号上。

适用人群：想要箱体模拟的吉他手和贝斯手、需要卷积混响的音频工程师，以及需要 TPDF 抖动、最小相位转换和高质量重采样的母带工程师。

与众不同之处：它使用 PFFFT 库（Pretty Fast FFT）进行实 FFT 卷积 —— 对于真实音频信号，速度是复数 FFT 的两倍。它包括母带级 TPDF 抖动（带误差反馈）、最小相位转换（消除预振铃）和多引擎重采样（SoX、R8Brain、FinalCD、线性回退）。它还可以将两个 IR 合并为一个新的 —— 混合两个箱体、将 EQ 固化到箱体中，或将箱体与房间融合。

  • 使用 PFFFT 的 FFT 卷积（SIMD 加速）
  • 带误差反馈的 TPDF 抖动（16 位）
  • 最小相位转换（无预振铃）
  • 多引擎重采样（SoX / R8Brain / FinalCD / 线性）
  • IR 组合（合并两个脉冲响应）
  • 淡入淡出、静音修剪、归一化、截断
  • 用于批量处理的 CLI，用于交互式使用的 GUI

乐器设置

StringSelectorApp

一款用于吉他和贝斯的琴弦张力计算器。它根据规格、单位重量、调音和有效弦长计算每根弦的精确张力 —— 并生成可打印的工坊报告。

适用人群：吉他技师、制琴师、贝斯手，以及任何需要为某种调音选择合适琴弦、设置多弦长乐器或在调整桁架杆前检查张力的人。

与众不同之处：它使用单位重量（而不仅仅是规格）来精确计算张力 —— 两个不同品牌的 .010" 琴弦可能有 20% 的张力差异。它包括可视化张力曲线、桁架杆调整助手（根据张力差估算圈数）和可打印的 HTML 工坊报告。它支持 4–9 弦乐器和多弦长（fanned-fret）有效弦长。

  • 37 个琴弦套装（Ernie Ball、D'Addario、Elixir 等）
  • 28 个调音预设（标准、Drop、Open、自定义）
  • 实时可视化张力曲线
  • 桁架杆调整助手（估算圈数）
  • 可打印的 HTML 工坊报告
  • CSV 导出、保存自定义调音、移调/音高
  • ISO 单位切换（lbs / kg / N）
  • 多弦长支持（高音 + 低音弦长）

无头录音

ChameleonRecorder

一个用于 Raspberry Pi 4（64 位）的无头、即插即用多轨 WAV 录音操作系统。它会自动检测任何符合 USB 音频设备类别的接口，将未压缩的 24 位多轨 WAV 文件直接录制到 USB 闪存盘，并提供支持移动设备的网页遥控器，带实时电平表。

适用人群：需要在没有笔记本电脑的情况下录制多轨音频的现场扩声工程师、排练室和音乐人。也适用于装置录音、合唱/管弦乐采集，以及任何相较于计算机更倾向使用专用、静音、低功耗录音机的场景。

与众不同之处：没有笔记本电脑。没有 DAW。没有驱动。只需一个 Raspberry Pi、一个 USB 音频接口和一个 USB 闪存盘。开机即录。它包括自动回退 Wi-Fi 热点（SSID：ChameleonRecorder），即使没有路由器也能工作 —— 连接手机即可从浏览器控制一切。它支持多设备录音（同时使用多个 USB 接口）、ADAT 时钟同步用于采样精确的多单元设置，以及可选的 GPIO 按钮用于物理录制/停止控制。

  • 通用 USB 音频支持（Behringer、MOTU、Focusrite、RME、Zoom 等）
  • 多设备录音，自动 ADAT 时钟同步
  • 网页遥控器位于端口 :8080（按设备和按通道布防，实时电平）
  • 回退 Wi-Fi 热点（无需路由器）
  • 24 位/48kHz WAV 直接录制到 USB 闪存盘
  • GPIO 按钮 + 状态 LED（可选）
  • 文件管理：删除、下载、ZIP 归档
  • 面向高级用户的 SSH 访问

适用人群

ChameleonTools 专为与声音打交道的人打造 —— 无论你是在写歌、录制唱片、母带处理音频还是设置乐器。以下是每个工具的受益者：

词曲作者与作曲家

ChameleonDrummer 可在任何类型或风格中生成逼真的 MIDI 鼓轨。勾勒编曲、制作伴奏轨并导出到你的 DAW。无需鼓手。

吉他手与贝斯手

TaraDSP 使用 FFT 卷积模拟箱体和效果。StringSelectorApp 帮助你为你的调音和有效弦长选择合适的琴弦。

音频与母带工程师

TaraDSP 提供 TPDF 抖动、最小相位转换、高质量重采样和卷积混响 —— 全部集成在一个轻量、可脚本化的 CLI 工具中。

吉他技师与制琴师

StringSelectorApp 计算琴弦张力、生成工坊报告并估算桁架杆调整。专业选弦的得力助手。

制作人与节拍制作人

ChameleonDrummer 在 37 种风格中创建富有人类感觉的鼓轨。TaraDSP 增加箱体模拟、混响和母带处理。完整的制作链。

现场扩声与排练室

ChameleonRecorder 将 Raspberry Pi 变成一台专用多轨录音机。插入 USB 调音台，插入 USB 闪存盘，直接录制每个通道 —— 没有笔记本电脑，没有 DAW，没有驱动问题。

FreePascal / Lazarus 开发者

桌面工具使用 FreePascal 和 Lazarus 构建。ChameleonRecorder 在 Raspberry Pi OS（Linux）上运行，使用 JACK、jack_capture 和 Python。多平台模板提供一套开箱即用的构建系统，支持 CI/CD、交叉编译和打包。

开源。开放的可能。

每个 ChameleonTools 项目都是免费且开源的。这不是营销决策 —— 而是一项基本原则。音乐工具应当人人可用，无论预算如何。而打造优秀工具的最佳方式，就是让社区使用、修改和改进它们。

无供应商锁定

由于工具是开源的并使用标准文件格式（WAV、MIDI、JSON、INI），因此不存在锁定。你的数据属于你。你的工作流程属于你。如果你决定切换到其他工具，你的文件仍然可以使用。

为 Fork 而设计

每个工具都被设计成一个起点，而非成品。Fork 它、修改它、把它变成你自己的。项目模板为你提供与这些工具相同的多平台构建系统、CI 工作流和打包方式 —— 让你的 Fork 能够像原版一样构建和发布。

社区驱动

欢迎在每个项目中提交错误报告、功能请求和 pull request。这些工具由一位每天使用它们的开发者构建，但社区的反馈塑造着它们的方向。如果某些东西对你不起作用，请开一个 issue —— 它会被审阅。

所有工具共享同一套构建系统： FreePascal + Lazarus + 一个多平台构建脚本，可生成 Windows 安装程序、macOS 应用包和 Linux tarball —— 并配有 GitHub Actions CI 工作流来自动化一切。一条工具链，五个平台，零手动步骤。

一套构建系统。每个平台。

所有 ChameleonTools 项目共享同一套多平台构建系统，已提取到一个可复用的项目模板中。它负责：

平台产物打包
Windows x86_64安装程序 (`.exe`)Inno Setup 6
macOS Intel (x86_64)应用包 (`.app` → `.zip`)zip_app.py（Unix 执行位）
macOS Apple Silicon (aarch64)应用包 (`.app` → `.zip`)zip_app.py（Unix 执行位）
Linux x86_64Tarball (`.tar.gz`)带执行位的两遍 tar
Linux ARMTarball (`.tar.gz`)带执行位的两遍 tar

本地构建

./build_all.bat            # 全部 5 个目标 + 打包到 Deploy/
./build_all.bat --check    # 仅验证工具链

在 CI 中构建

每个项目都包含一个 GitHub Actions 工作流，在 Windows runner 上构建全部 5 个目标。它通过 fpcup 安装 FPC + Lazarus + 交叉编译器，自动下载 macOS SDK，并运行 build_all.bat。通过 Actions → CI / Cross-Platform Build → Run workflow 手动触发。

前置条件

  • FreePascal Compiler (FPC) 3.2.2+ 或 Lazarus IDE 3.0+
  • FPC 交叉编译器（ppcrossx64、ppcrossa64、ppcrossarm）—— 通过 fpcupdeluxe 安装
  • Inno Setup 6（用于 Windows 安装程序）
  • Python 3（用于以正确的 Unix 模式打包 macOS 应用包）
  • Zig（自动下载，用于 TaraDSP 中 Linux C 交叉编译）
