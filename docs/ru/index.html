Одна экосистема. Четыре инструмента.

ChameleonTools — это коллекция профессиональных аудио- и музыкальных инструментов — настольные приложения, созданные с FreePascal и Lazarus, и headless-ОС для записи на Raspberry Pi. Каждый инструмент работает самостоятельно, но вместе они образуют полный рабочий процесс для музыкантов, звукоинженеров и продюсеров — от написания песен и звукового дизайна до сведения, мастеринга и настройки инструментов.

Каждый инструмент бесплатный, с открытым кодом и кроссплатформенный (Windows, macOS, Linux). Никаких подписок, никаких донглов, никакой привязки к поставщику. Скачивайте, используйте, изменяйте и вносите вклад.

ГЕНЕРАЦИЯ MIDI

ChameleonDrummer

Динамический генератор барабанов MIDI, который превращает жанр, стиль, барабанщика и размер в реалистичную, живую барабанную партию. Он экспортирует MIDI-файлы, которые можно импортировать в любую DAW, программу для барабанов или нотный редактор.

Для кого: Авторы песен, продюсеры и композиторы, которым нужны реалистичные барабанные партии без барабанщика или полного барабанного набора. Также полезен для генерации идей, набросков аранжировок и создания аккомпанирующих треков.

Чем он отличается: Он не просто зацикливает сэмплы — он моделирует стили барабанщиков (Bonham, Porcaro, Chambers, Roeder, Dee, Hoglan и ещё 10), применяет гуманизацию (джиттер тайминга, ghost notes, свинг) и соблюдает физические ограничения играбельности. Результат звучит как настоящий барабанщик, а не как машина.

  • 5 жанров, 37 стилей, 17 профилей барабанщиков
  • Поддержка нескольких keymap (GM, AD2, EZDrummer 3, Yamaha XG, пользовательский JSON)
  • Составные и нечётные размеры (5/4, 7/8, 9/8, 11/8, 13/8, до 32/16)
  • Триольный грув, свинг и гуманизация
  • Экспорт сессий REAPER и Ardour
  • CLI для пакетной генерации, GUI для интерактивного использования

АУДИО-КОНВОЛЮЦИЯ И МАСТЕРИНГ

TaraDSP

Профессиональный процессор конволюции на основе FFT для симуляции кабинетов, конволюционной реверберации и аудиообработки уровня мастеринга. Он применяет импульсные характеристики к аудиосигналам со студийным качеством.

Для кого: Гитаристы и басисты, которым нужна симуляция кабинетов, звукоинженеры, которым нужна конволюционная реверберация, и инженеры мастеринга, которым нужны TPDF-дитеринг, конверсия в минимальную фазу и высококачественный ресемплинг.

Чем он отличается: Он использует библиотеку PFFFT (Pretty Fast FFT) для реальной FFT-конволюции — вдвое быстрее комплексной FFT для реальных аудиосигналов. Он включает TPDF-дитеринг уровня мастеринга с обратной связью по ошибке, конверсию в минимальную фазу (убирает pre-ringing) и мульти-движковый ресемплинг (SoX, R8Brain, FinalCD, линейный fallback). Он также может объединить два IR в один новый — смешать два кабинета, «запечь» EQ в кабинет или слить кабинет с помещением.

  • FFT-конволюция с PFFFT (ускорение SIMD)
  • TPDF-дитеринг с обратной связью по ошибке (16-бит)
  • Конверсия в минимальную фазу (без pre-ringing)
  • Мульти-движковый ресемплинг (SoX / R8Brain / FinalCD / линейный)
  • Объединение IR (слияние двух импульсных характеристик)
  • Фейды, обрезка тишины, нормализация, усечение
  • CLI для пакетной обработки, GUI для интерактивного использования

НАСТРОЙКА ИНСТРУМЕНТОВ

StringSelectorApp

Калькулятор натяжения струн для гитар и басов. Он вычисляет точное натяжение каждой струны на основе калибра, удельного веса, строя и длины мензуры — и генерирует печатные мастерские отчёты.

Для кого: Гитарные мастера, лютьеры, басисты и все, кому нужно подобрать правильные струны для строя, настроить мультимензурный инструмент или проверить натяжение перед регулировкой анкера.

Чем он отличается: Он использует удельный вес (а не только калибр) для точного расчёта натяжения — две струны .010" разных брендов могут иметь на 20% разное натяжение. Он включает визуальную кривую натяжения, помощник регулировки анкера (оценка оборотов на основе разницы натяжения) и печатные HTML-отчёты для мастерской. Поддерживает инструменты с 4–9 струнами и мультимензурные (fanned-fret) длины мензуры.

  • 37 наборов струн (Ernie Ball, D'Addario, Elixir и другие)
  • 28 пресетов строя (Standard, Drop, Open, пользовательский)
  • Визуальная кривая натяжения в реальном времени
  • Помощник регулировки анкера (оценка оборотов)
  • Печатные HTML-отчёты для мастерской
  • Экспорт CSV, сохранение пользовательского строя, транспозиция/высота
  • Переключение единиц ISO (lbs / kg / N)
  • Поддержка мультимензуры (верхняя + нижняя мензура)

HEADLESS-ЗАПИСЬ

ChameleonRecorder

Headless-ОС для многодорожечной записи WAV с plug-and-play для Raspberry Pi 4 (64-бит). Она автоматически обнаруживает любой USB-аудиоинтерфейс, совместимый с классом, записывает несжатые 24-битные многодорожечные WAV-файлы напрямую на USB-флешку и предоставляет адаптированный для мобильных веб-пульт с живыми индикаторами уровня.

Для кого: Звукоинженеры живого звука, репетиционные студии и музыканты, которым нужно записывать многодорожечный звук без ноутбука. Также полезно для записи инсталляций, захвата хора/оркестра и любой ситуации, когда выделенный, тихий, энергоэффективный рекордер предпочтительнее компьютера.

Чем он отличается: Без ноутбука. Без DAW. Без драйверов. Только Raspberry Pi, USB-аудиоинтерфейс и USB-флешка. Включите и записывайте. Он включает автоматический резервный Wi-Fi-хотспот (SSID: ChameleonRecorder), чтобы работать даже без роутера — подключите телефон и управляйте всем из браузера. Поддерживает запись с нескольких устройств (несколько USB-интерфейсов одновременно), синхронизацию тактов ADAT для прецизионных мульти-юнит-сетапов и опциональные GPIO-кнопки для физического управления Record/Stop.

  • Универсальная поддержка USB-аудио (Behringer, MOTU, Focusrite, RME, Zoom и т.д.)
  • Запись с нескольких устройств с автоматической синхронизацией тактов ADAT
  • Веб-пульт на порту :8080 (арминг по устройству и по каналу, живые индикаторы)
  • Резервный Wi-Fi-хотспот (роутер не нужен)
  • Запись WAV 24-бит/48кГц напрямую на USB-флешку
  • GPIO-кнопки + светодиод статуса (опционально)
  • Управление файлами: удаление, скачивание, ZIP-архив
  • SSH-доступ для опытных пользователей

Для кого

ChameleonTools создан для людей, которые работают со звуком — пишете ли вы песни, записываете альбомы, мастерите аудио или настраиваете инструменты. Вот кому полезен каждый инструмент:

Авторы песен и композиторы

ChameleonDrummer генерирует реалистичные MIDI-барабанные партии в любом жанре или стиле. Набрасывайте аранжировки, создавайте аккомпанирующие треки и экспортируйте в свою DAW. Барабанщик не нужен.

Гитаристы и басисты

TaraDSP симулирует кабинеты и эффекты с помощью FFT-конволюции. StringSelectorApp помогает подобрать правильные струны для вашего строя и длины мензуры.

Звуко- и мастеринг-инженеры

TaraDSP предоставляет TPDF-дитеринг, конверсию в минимальную фазу, высококачественный ресемплинг и конволюционную реверберацию — всё в лёгком, скриптуемом CLI-инструменте.

Гитарные мастера и лютьеры

StringSelectorApp рассчитывает натяжение струн, генерирует мастерские отчёты и оценивает регулировки анкера. Профессиональный помощник по подбору струн.

Продюсеры и битмейкеры

ChameleonDrummer создаёт живые барабанные партии в 37 стилях. TaraDSP добавляет симуляцию кабинетов, реверберацию и мастеринг. Полная производственная цепочка.

Живой звук и репетиционные студии

ChameleonRecorder превращает Raspberry Pi в выделенный многодорожечный рекордер. Подключите USB-микшер, вставьте USB-флешку и записывайте каждый канал напрямую — без ноутбука, без DAW, без проблем с драйверами.

Разработчики FreePascal / Lazarus

Настольные инструменты созданы с FreePascal и Lazarus. ChameleonRecorder работает на Raspberry Pi OS (Linux) с использованием JACK, jack_capture и Python. Мультиплатформенный шаблон предоставляет готовую систему сборки с CI/CD, кросс-компиляцией и упаковкой.

Открытый код. Открытые возможности.

Каждый проект ChameleonTools бесплатный и с открытым кодом. Это не маркетинговое решение — это фундаментальный принцип. Музыкальные инструменты должны быть доступны каждому, независимо от бюджета. А лучший способ создавать отличные инструменты — позволить сообществу использовать, изменять и улучшать их.

Никакой привязки к поставщику

Поскольку инструменты открыты и используют стандартные форматы файлов (WAV, MIDI, JSON, INI), привязки нет. Ваши данные принадлежат вам. Ваш рабочий процесс принадлежит вам. Если вы решите перейти на другой инструмент, ваши файлы продолжат работать.

Создан для форков

Каждый инструмент задуман как отправная точка, а не как готовый продукт. Форкните, измените, сделайте его своим. Шаблон проекта даёт вам ту же мультиплатформенную систему сборки, CI-процесс и упаковку, что и эти инструменты — чтобы ваш форк мог собираться и выпускаться так же, как оригиналы.

Одна система сборки. Любая платформа.

Все проекты ChameleonTools используют одну мультиплатформенную систему сборки, вынесенную в переиспользуемый шаблон проекта. Она обрабатывает:

ПлатформаАртефактУпаковка
Windows x86_64Установщик (`.exe`)Inno Setup 6
macOS Intel (x86_64)App bundle (`.app` → `.zip`)zip_app.py (биты исполнения Unix)
macOS Apple Silicon (aarch64)App bundle (`.app` → `.zip`)zip_app.py (биты исполнения Unix)
Linux x86_64Tarball (`.tar.gz`)Двухпроходный tar с битами исполнения
Linux ARMTarball (`.tar.gz`)Двухпроходный tar с битами исполнения

Сборка локально

./build_all.bat            # все 5 целей + пакеты в Deploy/
./build_all.bat --check    # проверить только цепочку инструментов

Сборка в CI

Каждый проект включает workflow GitHub Actions, который собирает все 5 целей на Windows-раннере. Он устанавливает FPC + Lazarus + кросс-компиляторы через fpcup, автоматически скачивает macOS SDK и запускает build_all.bat. Запустите его вручную через Actions → CI / Cross-Platform Build → Run workflow.

Предварительные требования

  • FreePascal Compiler (FPC) 3.2.2+ или Lazarus IDE 3.0+
  • Кросс-компиляторы FPC (ppcrossx64, ppcrossa64, ppcrossarm) — устанавливаются через fpcupdeluxe
  • Inno Setup 6 (для установщика Windows)
  • Python 3 (для упаковки app bundles macOS с правильными Unix-режимами)
  • Zig (автоматически скачивается для кросс-компиляции C под Linux в TaraDSP)
