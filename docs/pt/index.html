Um ecossistema. Quatro instrumentos.

O ChameleonTools é uma coleção de ferramentas profissionais de áudio e música — aplicativos de desktop desenvolvidos com FreePascal e Lazarus, e um sistema operacional de gravação headless para Raspberry Pi. Cada ferramenta funciona por conta própria, mas juntas formam um fluxo de trabalho completo para músicos, engenheiros de áudio e produtores — da composição e do design de som à mixagem, masterização e configuração de instrumentos.

Cada ferramenta é gratuita, de código aberto e multiplataforma (Windows, macOS, Linux). Sem assinaturas, sem dongles, sem lock-in de fornecedor. Baixe, use, modifique e contribua.

GERAÇÃO DE MIDI

ChameleonDrummer

Um gerador dinâmico de bateria MIDI que transforma um gênero, um estilo, um baterista e um compasso em uma faixa de bateria realista e com feeling humano. Ele exporta arquivos MIDI que você pode importar em qualquer DAW, software de bateria ou programa de notação.

Para quem é: Compositores, produtores e criadores que precisam de faixas de bateria realistas sem um baterista ou um kit de bateria completo. Também é útil para gerar ideias, esboçar arranjos e criar faixas de acompanhamento.

O que o torna diferente: Ele não apenas faz loop de samples — modela estilos de bateristas (Bonham, Porcaro, Chambers, Roeder, Dee, Hoglan e mais 10), aplica humanização (jitter de timing, ghost notes, swing) e respeita os limites físicos de execução. O resultado soa como um baterista real, não como uma máquina.

  • 5 gêneros, 37 estilos, 17 perfis de baterista
  • Suporte a múltiplos keymaps (GM, AD2, EZDrummer 3, Yamaha XG, JSON personalizado)
  • Compassos compostos e ímpares (5/4, 7/8, 9/8, 11/8, 13/8, até 32/16)
  • Feel de tercinas, swing e humanização
  • Exportação de sessão para REAPER e Ardour
  • CLI para geração em lote, GUI para uso interativo

CONVOLUÇÃO DE ÁUDIO E MASTERIZAÇÃO

TaraDSP

Um processador de convolução profissional baseado em FFT para simulação de caixas, reverb por convolução e processamento de áudio de nível masterização. Ele aplica respostas de impulso a sinais de áudio com qualidade de estúdio.

Para quem é: Guitarristas e baixistas que querem simulação de caixas, engenheiros de áudio que precisam de reverb por convolução e engenheiros de masterização que precisam de dithering TPDF, conversão de fase mínima e reamostragem de alta qualidade.

O que o torna diferente: Ele usa a biblioteca PFFFT (Pretty Fast FFT) para convolução de FFT real — duas vezes mais rápido que a FFT complexa para sinais de áudio reais. Inclui dithering TPDF de nível masterização com realimentação de erro, conversão de fase mínima (remove o pre-ringing) e reamostragem multi-engine (SoX, R8Brain, FinalCD, fallback linear). Também pode combinar dois IRs em um novo — misturar duas caixas, gravar EQ em uma caixa ou fundir uma caixa com uma sala.

  • Convolução FFT com PFFFT (acelerada por SIMD)
  • Dithering TPDF com realimentação de erro (16-bit)
  • Conversão de fase mínima (sem pre-ringing)
  • Reamostragem multi-engine (SoX / R8Brain / FinalCD / linear)
  • Combinação de IR (fundir duas respostas de impulso)
  • Fades, corte de silêncio, normalização, truncamento
  • CLI para processamento em lote, GUI para uso interativo

CONFIGURAÇÃO DE INSTRUMENTOS

StringSelectorApp

Uma calculadora de tensão de cordas para guitarras e baixos. Ela calcula a tensão exata de cada corda com base na bitola, no peso unitário, na afinação e no comprimento de escala — e gera relatórios de oficina imprimíveis.

Para quem é: Técnicos de guitarra, luthiers, baixistas e qualquer pessoa que precise escolher as cordas certas para uma afinação, configurar um instrumento multiescala ou verificar a tensão antes de um ajuste de alma.

O que o torna diferente: Ele usa o peso unitário (não apenas a bitola) para um cálculo de tensão preciso — duas cordas .010" de marcas diferentes podem ter 20% de tensão diferente. Inclui uma curva de tensão visual, um assistente de ajuste de alma (voltas estimadas com base na diferença de tensão) e relatórios de oficina em HTML imprimíveis. Suporta instrumentos de 4–9 cordas e comprimentos de escala multiescala (fanned-fret).

  • 37 packs de cordas (Ernie Ball, D'Addario, Elixir e mais)
  • 28 presets de afinação (Padrão, Drop, Open, personalizada)
  • Curva de tensão visual em tempo real
  • Assistente de ajuste de alma (voltas estimadas)
  • Relatórios de oficina em HTML imprimíveis
  • Exportação CSV, salvar afinação personalizada, transpor/pitch
  • Alternância de unidades ISO (lbs / kg / N)
  • Suporte multiescala (escala aguda + grave)

GRAVAÇÃO HEADLESS

ChameleonRecorder

Um sistema operacional de gravação WAV multitrack headless e plug-and-play para Raspberry Pi 4 (64-bit). Ele detecta automaticamente qualquer interface de áudio USB compatível com a classe, grava arquivos WAV multitrack descompactados de 24-bit diretamente em um pen drive USB e oferece um controle remoto web compatível com celulares com medidores de nível ao vivo.

Para quem é: Engenheiros de som ao vivo, estúdios de ensaio e músicos que precisam gravar áudio multitrack sem um notebook. Também é útil para gravação de instalações, captação de coral/orquestra e qualquer situação em que um gravador dedicado, silencioso e de baixo consumo seja preferível a um computador.

O que o torna diferente: Sem notebook. Sem DAW. Sem drivers. Apenas um Raspberry Pi, uma interface de áudio USB e um pen drive. Ligue e grave. Ele inclui um hotspot Wi-Fi de fallback automático (SSID: ChameleonRecorder) para funcionar mesmo sem roteador — conecte seu telefone e controle tudo pelo navegador. Suporta gravação multi-dispositivo (várias interfaces USB simultâneas), sincronização de clock ADAT para configurações multi-unidade com precisão de amostra e botões de pressão GPIO opcionais para controle físico de Record/Stop.

  • Suporte universal de áudio USB (Behringer, MOTU, Focusrite, RME, Zoom, etc.)
  • Gravação multi-dispositivo com sincronização automática de clock ADAT
  • Controle remoto web na porta :8080 (armamento por dispositivo e por canal, medidores ao vivo)
  • Hotspot Wi-Fi de fallback (sem necessidade de roteador)
  • Gravação WAV de 24-bit/48kHz diretamente no pen drive USB
  • Botões GPIO + LED de status (opcional)
  • Gerenciamento de arquivos: excluir, baixar, arquivo ZIP
  • Acesso SSH para usuários avançados

Para quem

O ChameleonTools foi criado para pessoas que trabalham com som — seja compondo músicas, gravando discos, masterizando áudio ou configurando instrumentos. Veja quem se beneficia de cada ferramenta:

Compositores e criadores

ChameleonDrummer gera faixas de bateria MIDI realistas em qualquer gênero ou estilo. Esboce arranjos, crie faixas de acompanhamento e exporte para o seu DAW. Nenhum baterista necessário.

Guitarristas e baixistas

TaraDSP simula caixas e efeitos com convolução FFT. StringSelectorApp ajuda você a escolher as cordas certas para sua afinação e comprimento de escala.

Engenheiros de áudio e masterização

TaraDSP oferece dithering TPDF, conversão de fase mínima, reamostragem de alta qualidade e reverb por convolução — tudo em uma ferramenta CLI leve e automatizável.

Técnicos de guitarra e luthiers

StringSelectorApp calcula a tensão das cordas, gera relatórios de oficina e estima ajustes de alma. O companheiro profissional para a seleção de cordas.

Produtores e beatmakers

ChameleonDrummer cria faixas de bateria com feeling humano em 37 estilos. TaraDSP adiciona simulação de caixas, reverb e masterização. A cadeia de produção completa.

Som ao vivo e estúdios de ensaio

ChameleonRecorder transforma um Raspberry Pi em um gravador multitrack dedicado. Conecte sua mesa USB, insira um pen drive e grave cada canal diretamente — sem notebook, sem DAW, sem problemas de drivers.

Desenvolvedores FreePascal / Lazarus

As ferramentas de desktop são desenvolvidas com FreePascal e Lazarus. O ChameleonRecorder roda no Raspberry Pi OS (Linux) usando JACK, jack_capture e Python. O template multiplataforma fornece um sistema de build pronto para uso com CI/CD, compilação cruzada e empacotamento.

Código aberto. Possibilidades abertas.

Todo projeto ChameleonTools é gratuito e de código aberto. Isso não é uma decisão de marketing — é um princípio fundamental. Ferramentas musicais deveriam ser acessíveis a todos, independentemente do orçamento. E a melhor forma de criar ótimas ferramentas é permitir que a comunidade as use, modifique e melhore.

O que "código aberto" significa aqui

LiberdadeO que isso significa para você
UsarBaixe, instale e use cada ferramenta gratuitamente. Sem assinaturas, sem testes, sem limites de recursos.

ContribuirFaça fork do repositório, faça melhorias e envie um pull request. Cada contribuição torna as ferramentas melhores para todos.

Sem lock-in de fornecedor

Como as ferramentas são de código aberto e usam formatos de arquivo padrão (WAV, MIDI, JSON, INI), não há lock-in. Seus dados são seus. Seu fluxo de trabalho é seu. Se você decidir mudar para outra ferramenta, seus arquivos continuarão funcionando.

Feito para ser forkado

Cada ferramenta é projetada como um ponto de partida, não como um produto finalizado. Faça fork, mude, torne-a sua. O template de projeto oferece o mesmo sistema de build multiplataforma, fluxo de CI e empacotamento que essas ferramentas usam — para que seu fork possa compilar e lançar como os originais.

Movido pela comunidade

Relatórios de bugs, solicitações de recursos e pull requests são bem-vindos em cada projeto. As ferramentas são desenvolvidas por um desenvolvedor que as usa diariamente, mas o feedback da comunidade molda sua direção. Se algo não funcionar para você, abra uma issue — ela será analisada.

Todas as ferramentas compartilham o mesmo sistema de build: FreePascal + Lazarus + um script de build multiplataforma que produz instaladores Windows, app bundles macOS e tarballs Linux — com um fluxo de CI do GitHub Actions que automatiza tudo. Uma cadeia de ferramentas, cinco plataformas, zero passos manuais.

Compilar localmente

./build_all.bat            # os 5 alvos + pacotes em Deploy/
./build_all.bat --check    # verificar apenas a cadeia de ferramentas

Compilar no CI

Cada projeto inclui um workflow do GitHub Actions que compila os 5 alvos em um runner Windows. Ele instala FPC + Lazarus + compiladores cruzados via fpcup, baixa automaticamente o SDK do macOS e executa build_all.bat. Dispare-o manualmente via Actions → CI / Cross-Platform Build → Run workflow.

Pré-requisitos

  • FreePascal Compiler (FPC) 3.2.2+ ou Lazarus IDE 3.0+
  • Compiladores cruzados FPC (ppcrossx64, ppcrossa64, ppcrossarm) — instalados via fpcupdeluxe
  • Inno Setup 6 (para o instalador Windows)
  • Python 3 (para compactar app bundles macOS com os modos Unix corretos)
  • Zig (baixado automaticamente para a compilação cruzada de C no Linux no TaraDSP)
