Un ecosistema. Cuatro instrumentos.

ChameleonTools es una colección de herramientas profesionales de audio y música — aplicaciones de escritorio creadas con FreePascal y Lazarus, y un sistema operativo de grabación headless para Raspberry Pi. Cada herramienta funciona por sí sola, pero juntas forman un flujo de trabajo completo para músicos, ingenieros de audio y productores — desde la composición y el diseño de sonido hasta la mezcla, la masterización y la configuración de instrumentos.

Cada herramienta es gratuita, de código abierto y multiplataforma (Windows, macOS, Linux). Sin suscripciones, sin dongles, sin lock-in de proveedor. Descarga, usa, modifica y contribuye.

GENERACIÓN DE MIDI

ChameleonDrummer

Un generador dinámico de batería MIDI que convierte un género, un estilo, un baterista y un compás en una pista de batería realista y con feeling humano. Exporta archivos MIDI que puedes importar en cualquier DAW, software de batería o programa de notación.

Para quién es: Compositores, productores y creadores que necesitan pistas de batería realistas sin un baterista ni un kit de batería completo. También es útil para generar ideas, esbozar arreglos y crear pistas de acompañamiento.

Qué lo hace diferente: No solo hace loop de samples — modela estilos de bateristas (Bonham, Porcaro, Chambers, Roeder, Dee, Hoglan y 10 más), aplica humanización (jitter de timing, ghost notes, swing) y respeta las limitaciones físicas de interpretación. El resultado suena como un baterista real, no como una máquina.

  • 5 géneros, 37 estilos, 17 perfiles de baterista
  • Soporte de múltiples keymaps (GM, AD2, EZDrummer 3, Yamaha XG, JSON personalizado)
  • Compases compuestos e impares (5/4, 7/8, 9/8, 11/8, 13/8, hasta 32/16)
  • Feel de tresillos, swing y humanización
  • Exportación de sesión a REAPER y Ardour
  • CLI para generación por lotes, GUI para uso interactivo

CONVOLUCIÓN DE AUDIO Y MASTERIZACIÓN

TaraDSP

Un procesador de convolución profesional basado en FFT para simulación de cabinas, reverb de convolución y procesamiento de audio de grado masterización. Aplica respuestas de impulso a señales de audio con calidad de estudio.

Para quién es: Guitarristas y bajistas que quieren simulación de cabinas, ingenieros de audio que necesitan reverb de convolución, e ingenieros de masterización que necesitan dithering TPDF, conversión de fase mínima y resampling de alta calidad.

Qué lo hace diferente: Usa la biblioteca PFFFT (Pretty Fast FFT) para convolución de FFT real — el doble de rápido que la FFT compleja para señales de audio reales. Incluye dithering TPDF de grado masterización con realimentación de error, conversión de fase mínima (elimina el pre-ringing) y resampling multi-motor (SoX, R8Brain, FinalCD, fallback lineal). También puede combinar dos IR en uno nuevo — mezclar dos cabinas, grabar EQ en una cabina, o fusionar una cabina con una sala.

  • Convolución FFT con PFFFT (acelerada por SIMD)
  • Dithering TPDF con realimentación de error (16-bit)
  • Conversión de fase mínima (sin pre-ringing)
  • Resampling multi-motor (SoX / R8Brain / FinalCD / lineal)
  • Combinación de IR (fusionar dos respuestas de impulso)
  • Fades, recorte de silencio, normalización, truncamiento
  • CLI para procesamiento por lotes, GUI para uso interactivo

CONFIGURACIÓN DE INSTRUMENTOS

StringSelectorApp

Una calculadora de tensión de cuerdas para guitarras y bajos. Calcula la tensión exacta de cada cuerda según el calibre, el peso unitario, la afinación y la longitud de escala — y genera informes de taller imprimibles.

Para quién es: Técnicos de guitarra, lutieres, bajistas y cualquiera que necesite elegir las cuerdas correctas para una afinación, configurar un instrumento multiescala, o comprobar la tensión antes de un ajuste de alma.

Qué lo hace diferente: Usa el peso unitario (no solo el calibre) para un cálculo de tensión preciso — dos cuerdas .010" de diferentes marcas pueden tener un 20% de tensión diferente. Incluye una curva de tensión visual, un asistente de ajuste de alma (vueltas estimadas según la diferencia de tensión) e informes de taller en HTML imprimibles. Soporta instrumentos de 4–9 cuerdas y longitudes de escala multiescala (fanned-fret).

  • 37 packs de cuerdas (Ernie Ball, D'Addario, Elixir y más)
  • 28 presets de afinación (Estándar, Drop, Open, personalizada)
  • Curva de tensión visual en tiempo real
  • Asistente de ajuste de alma (vueltas estimadas)
  • Informes de taller en HTML imprimibles
  • Exportación CSV, guardar afinación personalizada, transportar/tono
  • Cambio de unidades ISO (lbs / kg / N)
  • Soporte multiescala (escala de agudos + graves)

GRABACIÓN HEADLESS

ChameleonRecorder

Un sistema operativo de grabación multitrack WAV headless y plug-and-play para Raspberry Pi 4 (64-bit). Detecta automáticamente cualquier interfaz de audio USB compatible con la clase, graba archivos WAV multitrack sin comprimir de 24-bit directamente en una unidad flash USB, y proporciona un control remoto web apto para móviles con medidores de nivel en vivo.

Para quién es: Ingenieros de sonido en vivo, estudios de ensayo y músicos que necesitan grabar audio multitrack sin un portátil. También es útil para grabación de instalaciones, captación de coro/orquesta, y cualquier situación en la que se prefiera un grabador dedicado, silencioso y de bajo consumo sobre un ordenador.

Qué lo hace diferente: Sin portátil. Sin DAW. Sin controladores. Solo un Raspberry Pi, una interfaz de audio USB y una memoria USB. Enciende y graba. Incluye un hotspot Wi-Fi de respaldo automático (SSID: ChameleonRecorder) para que funcione incluso sin router — conecta tu teléfono y controla todo desde el navegador. Soporta grabación multi-dispositivo (múltiples interfaces USB simultáneas), sincronización de reloj ADAT para configuraciones multi-unidad con precisión de muestra, y pulsadores GPIO opcionales para control físico de grabación/parada.

  • Soporte universal de audio USB (Behringer, MOTU, Focusrite, RME, Zoom, etc.)
  • Grabación multi-dispositivo con sincronización automática de reloj ADAT
  • Control remoto web en el puerto :8080 (armado por dispositivo y por canal, medidores en vivo)
  • Hotspot Wi-Fi de respaldo (sin necesidad de router)
  • Grabación WAV de 24-bit/48kHz directamente en unidad flash USB
  • Pulsadores GPIO + LED de estado (opcional)
  • Gestión de archivos: eliminar, descargar, archivo ZIP
  • Acceso SSH para usuarios avanzados

Para quién

ChameleonTools está creada para personas que trabajan con el sonido — ya sea que escribas canciones, grabes discos, masterices audio o configures instrumentos. Esto es quién se beneficia de cada herramienta:

Compositores y creadores

ChameleonDrummer genera pistas de batería MIDI realistas en cualquier género o estilo. Esboza arreglos, crea pistas de acompañamiento y exporta a tu DAW. No se necesita baterista.

Guitarristas y bajistas

TaraDSP simula cabinas y efectos con convolución FFT. StringSelectorApp te ayuda a elegir las cuerdas correctas para tu afinación y longitud de escala.

Ingenieros de audio y masterización

TaraDSP proporciona dithering TPDF, conversión de fase mínima, resampling de alta calidad y reverb de convolución — todo en una herramienta CLI ligera y automatizable.

Técnicos de guitarra y lutieres

StringSelectorApp calcula la tensión de cuerdas, genera informes de taller y estima ajustes de alma. El compañero profesional para la selección de cuerdas.

Productores y beatmakers

ChameleonDrummer crea pistas de batería con feeling humano en 37 estilos. TaraDSP añade simulación de cabinas, reverb y masterización. La cadena de producción completa.

Sonido en vivo y estudios de ensayo

ChameleonRecorder convierte un Raspberry Pi en un grabador multitrack dedicado. Conecta tu mezclador USB, inserta una memoria USB y graba cada canal directamente — sin portátil, sin DAW, sin problemas de controladores.

Desarrolladores de FreePascal / Lazarus

Las herramientas de escritorio están creadas con FreePascal y Lazarus. ChameleonRecorder funciona en Raspberry Pi OS (Linux) usando JACK, jack_capture y Python. La plantilla multiplataforma proporciona un sistema de compilación listo para usar con CI/CD, compilación cruzada y empaquetado.

Código abierto. Posibilidades abiertas.

Cada proyecto de ChameleonTools es gratuito y de código abierto. Esto no es una decisión de marketing — es un principio fundamental. Las herramientas musicales deberían ser accesibles para todos, independientemente del presupuesto. Y la mejor manera de crear grandes herramientas es dejar que la comunidad las use, modifique y mejore.

Qué significa "código abierto" aquí

Sin lock-in de proveedor

Como las herramientas son de código abierto y usan formatos de archivo estándar (WAV, MIDI, JSON, INI), no hay lock-in. Tus datos son tuyos. Tu flujo de trabajo es tuyo. Si decides cambiar a otra herramienta, tus archivos seguirán funcionando.

Creado para ser forkeado

Cada herramienta está diseñada como un punto de partida, no como un producto terminado. Haz fork, cámbiala, hazla tuya. La plantilla de proyecto te da el mismo sistema de compilación multiplataforma, flujo de CI y empaquetado que usan estas herramientas — para que tu fork pueda compilar y lanzar igual que los originales.

Impulsado por la comunidad

Los informes de errores, las solicitudes de funciones y los pull requests son bienvenidos en cada proyecto. Las herramientas están construidas por un desarrollador que las usa a diario, pero el feedback de la comunidad da forma a su dirección. Si algo no te funciona, abre un issue — será revisado.

Todas las herramientas comparten el mismo sistema de compilación: FreePascal + Lazarus + un script de compilación multiplataforma que produce instaladores de Windows, app bundles de macOS y tarballs de Linux — con un flujo de CI de GitHub Actions que automatiza todo. Una cadena de herramientas, cinco plataformas, cero pasos manuales.

Un sistema de compilación. Cada plataforma.

Compilar localmente

./build_all.bat            # los 5 objetivos + paquetes en Deploy/
./build_all.bat --check    # verificar solo la cadena de herramientas

Compilar en CI

Cada proyecto incluye un flujo de GitHub Actions que compila los 5 objetivos en un runner de Windows. Instala FPC + Lazarus + compiladores cruzados vía fpcup, descarga automáticamente el SDK de macOS, y ejecuta build_all.bat. Ejecútalo manualmente vía Actions → CI / Cross-Platform Build → Run workflow.

Requisitos previos

  • FreePascal Compiler (FPC) 3.2.2+ o Lazarus IDE 3.0+
  • Compiladores cruzados de FPC (ppcrossx64, ppcrossa64, ppcrossarm) — instalados vía fpcupdeluxe
  • Inno Setup 6 (para el instalador de Windows)
  • Python 3 (para el empaquetado de app bundles de macOS con los modos Unix correctos)
  • Zig (descargado automáticamente para la compilación cruzada de C en Linux en TaraDSP)
